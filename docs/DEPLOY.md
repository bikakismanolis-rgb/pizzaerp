# Για το τέλος: ό,τι θέλει πρόσβαση στη Supabase / Vercel

Μαζεμένα εδώ, για να γίνουν όλα μαζί όταν υπάρχει πρόσβαση. Τίποτα από
αυτά δεν έχει γίνει ακόμα.

## 1. Βάση (Supabase)

1. Backup της βάσης που δουλεύει.
2. Πρώτα σε δοκιμαστικό project ή branch της Supabase, μετά στην κανονική.
3. Στο SQL Editor, με αυτή τη σειρά:
   1. `supabase/migrations/0005_online.sql`
   2. `supabase/migrations/0006_pay_fiscal.sql`
   3. `supabase/migrations/0007_delivery.sql`
4. Αν ξανατρέξει ποτέ ένα από αυτά, ξανατρέχουν και όσα έρχονται μετά (π.χ.
   `0005` → και `0006`, `0007`).

## 2. Frontend (Vercel)

- Merge του PR στο `main`: το Vercel ανεβάζει μόνο του τη νέα έκδοση.
- Η εφαρμογή δουλεύει και πριν από το βήμα 1 (οι νέες επιλογές απλώς δεν
  φαίνονται), οπότε η σειρά δεν είναι κρίσιμη.

## 3. Ρυθμίσεις μέσα στην εφαρμογή (ο ιδιοκτήτης)

- **Αποδείξεις & τιμολόγια → Ρυθμίσεις:** «Από την ταμειακή, με αριθμό» μέχρι
  να ξέρουμε τον πάροχο. Συμπλήρωση στοιχείων εκδότη (δραστηριότητα, ΔΟΥ,
  πόλη, ΤΚ).
- **Ρυθμίσεις site:** διεύθυνση, ώρα κλεισίματος, μεταφορικά, ποια είδη
  φαίνονται, extras, επιβράβευση και έκπτωση καλωσορίσματος (αν θέλει).
- Εκτύπωση των QR για σακούλες και φυλλάδια (διαλέγει «Για πού» πριν από την εκτύπωση).
- Ένα πέρασμα της σελίδας απορρήτου (`/s/<slug>/privacy`): γράφει τα στοιχεία
  της εταιρείας (όνομα, ΑΦΜ, διεύθυνση) από τις ρυθμίσεις της. Αν θέλει, να
  τη δει και ο λογιστής ή δικηγόρος.
- Στο tablet της κουζίνας: άνοιγμα της οθόνης «Παραγγελίες», ένα άγγιγμα για
  τον ήχο, και αν υπάρχει εκτυπωτής, «Τύπωμα στην αποδοχή».
- **Διανομείς:** ένας-ένας στους «Διανομείς», σύνδεσμος με QR στο κινητό του,
  «Προσθήκη στην αρχική οθόνη». Αν θέλει ο πελάτης να βλέπει τη θέση: πρώτα
  ενημέρωση των διανομέων, μετά ο διακόπτης στους «Διανομείς».

## 4. Μόνο αν θέλει online πληρωμή ή CAPTCHA

1. Edge Functions (εντολές στο README, «Edge Functions (0006)») και
   `supabase secrets set SITE_URL=https://<το-site>`.
2. Ρυθμίσεις site → Πληρωμές → «Δοκιμαστική»: μία παραγγελία από άκρη σε άκρη.
3. Λογαριασμός στη Viva (ή Stripe), κλειδιά στις Ρυθμίσεις site, πρώτα με τον
   demo λογαριασμό / test mode και μετά πραγματικές πληρωμές.
4. Turnstile (προαιρετικό): widget στο Cloudflare, τα δύο κλειδιά στις
   Ρυθμίσεις site.

## 5. Ερωτήσεις για τον λογιστή

- Ποιον πάροχο ηλεκτρονικής τιμολόγησης έχει (για να γραφτεί η σύνδεση);
- Ποιες σειρές παραστατικών;
- ΦΠΑ στα μεταφορικά (τώρα 24%);
- Από πότε είναι υποχρεωτική για την επιχείρηση η ηλεκτρονική τιμολόγηση
  προς επιχειρήσεις (ξενοδοχεία);
- Οι εκπτώσεις (επιβράβευση, καλωσόρισμα) γράφονται ως έκπτωση στη γραμμή
  της πώλησης και της απόδειξης: εντάξει έτσι;
