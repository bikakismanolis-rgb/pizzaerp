# Pizza ERP — Web app

React + Vite + TypeScript + Tailwind, με Supabase (Postgres + Auth + RLS) στο backend.

## Ρυθμίσεις

Δημιούργησε αρχείο `.env` (υπάρχει ήδη `.env.example`):

```
VITE_SUPABASE_URL=https://gvqanbrexbrjtnlkbepo.supabase.co
VITE_SUPABASE_ANON_KEY=sb_publishable_...
```

Το publishable/anon key είναι σχεδιασμένο να είναι δημόσιο (η ασφάλεια γίνεται με RLS στη βάση).

## Απαιτήσεις

Node 18 ή νεότερο (δοκιμασμένο σε 20.15 και 22). Το toolchain είναι Vite 5 + Tailwind 3 + React 18.

## Τοπική εκτέλεση

```
cd web
npm install
npm run dev
```

Αν είχες τρέξει προηγούμενη έκδοση, σβήσε πρώτα `node_modules` και `package-lock.json` και ξανακάνε `npm install`.

Άνοιξε http://localhost:5173. Πρώτη φορά: κάνε εγγραφή με email/κωδικό, μετά δημιούργησε την επιχείρηση.

## Build

```
npm run build      # παράγει το dist/
npm run preview    # τοπική προεπισκόπηση του build
```

## Deploy στο Vercel

1. Ανέβασε το repo στο GitHub.
2. Στο Vercel: New Project → import το repo.
3. **Root Directory:** `web` (το app είναι σε υποφάκελο).
4. Framework preset: Vite. Build command `npm run build`, output `dist` (τα βρίσκει μόνο του).
5. Environment Variables: πρόσθεσε `VITE_SUPABASE_URL` και `VITE_SUPABASE_ANON_KEY`.
6. Deploy. Το `vercel.json` φροντίζει το SPA routing (όλα τα paths → index.html).

## Ροή χρήσης (σύντομα)

1. **Είδη**: φτιάξε πρώτες ύλες (αλεύρι, τυρί...), μετά ημιέτοιμα (ζυμάρια) με συνταγή, μετά έτοιμα προϊόντα (πίτσες) με συνταγή. Στις πίτσες λιανικής τσέκαρε «Φτιάχνεται κατά παραγγελία».
2. **Πελάτες & προμηθευτές**: ξενοδοχεία, μύλος, τυροκομείο. Στους πελάτες, tab «Τιμές» για ειδικό τιμοκατάλογο.
3. **Αγορές**: καταχώρησε τιμολόγια προμηθευτών.
4. **Παραγωγές**: ζυμάρια και κατεψυγμένες για χονδρική.
5. **Πωλήσεις ημέρας**: μετρητής λιανικής ανά κανάλι (efood, Wolt, box, τηλέφωνο, μαγαζί). Κάθε +/− γράφεται αμέσως σε ανοιχτό πρόχειρο (το βλέπουν όλες οι συσκευές)· «Κλείσιμο ημέρας» το καταχωρεί (backflush). Όσες μέρες μείνουν ανοιχτές κλείνουν αυτόματα στην επόμενη σύνδεση. Η πρώτη μέτρηση απογραφής ενός είδους καταχωρεί όσες πωλήσεις το κινούν ως εκείνη τη στιγμή· οι επόμενες μπαίνουν σε νέο ανοιχτό και τα σύνολα της ημέρας δείχνουν και τα δύο (τα +/− και το «βγάλε μία μαργαρίτα» αλλάζουν μόνο τις ανοιχτές· οι καταχωρημένες διορθώνονται από το παραστατικό τους). Στα σύνολα μετράνε μόνο οι «Πωλήσεις ημέρας»· άλλη πώληση με το ίδιο κανάλι (π.χ. τιμολόγιο σε πελάτη efood) φαίνεται χωριστά.
6. **Πωλήσεις**: χονδρική στα ξενοδοχεία.
7. **Απογραφή** (ολική στο τέλος του μήνα ή μερική, π.χ. μόνο αλεύρι): μετράς, το σύστημα ρίχνει τις διαφορές στο κόστος. Η μέτρηση μετράει τη στιγμή που γίνεται (στο «Πες το» τη στιγμή που λες το είδος, στην οθόνη απογραφής τη στιγμή της καταχώρησης): ό,τι πουληθεί ή φτιαχτεί μετά μετράει για μετά, οπότε η δουλειά συνεχίζει κανονικά. Κλειδώνουν μόνο όσα ήταν πριν από τη μέτρηση (παλιότερες ημερομηνίες, ακύρωση κίνησης που μετρήθηκε). Μέτρημα χώρο-χώρο: «αλεύρι 10 κιλά» … «αλεύρι άλλα 5 κιλά» = 15 (ή σκέτο «κι άλλα 5 κιλά» αμέσως μετά: το τελευταίο είδος), «αλεύρι σύνολο 40» = διόρθωση. Οι μετρήσεις μπαίνουν στη σημερινή απογραφή σε εξέλιξη· η χθεσινή συνεχίζει μόνο σε μέτρημα που πέρασε τα μεσάνυχτα (ως τις 5 το πρωί και πριν γραφτεί οτιδήποτε με σημερινή ημερομηνία). Απογραφή που ξεχάστηκε ανοιχτή από παλιότερη μέρα μένει χωριστά (δεν προστίθεται σε αυτήν) και το «τέλος απογραφής» τις καταχωρεί όλες, την παλιότερη πρώτη. Λάθος σε κίνηση που έγινε πριν από τη μέτρηση ενός είδους (π.χ. η πρωινή παραλαβή): στη σελίδα της απογραφής σε εξέλιξη «Βγάλε» το είδος, διόρθωσε την κίνηση και μέτρησέ το ξανά. Στις «Πωλήσεις ημέρας», παλιά μέρα πριν από καταχωρημένη απογραφή δείχνει σημείωση ότι είναι κλειδωμένη για τα προϊόντα που κινούν μετρημένα είδη.
8. **Αναφορές**: υπόλοιπα, καρτέλες, κόστος, κερδοφορία.
9. **Πες το** (`/voice`): πες ή γράψε τι έγινε («efood τρεις μαργαρίτες», «ήρθαν δέκα σακιά αλεύρι από τον μύλο», «μέτρησα μοτσαρέλα έξι κιλά»). Η οθόνη δείχνει (και διαβάζει) τι κατάλαβε, διορθώνεις ό,τι χρειάζεται, και μόνο με «Ναι, πέρασέ το» γράφεται κάτι. Κάθε ενέργεια έχει «Αναίρεση».
10. **Λέξεις & φράσεις** (`/voice/words`): δικές σας φράσεις («όταν λέω οικογενειακή εννοώ μεγάλη μαργαρίτα», και με φωνή· προτείνεται να μάθει και ο πληθυντικός, «οικογενειακές») και άλλα ονόματα ειδών / πελατών, με κουτί «Δοκίμασε». Οδηγός για το προσωπικό με όλες τις φράσεις: `docs/pes-to-odigos.pdf` (πηγή `docs/pes-to-odigos.html`· κάθε φράση του είναι ελεγμένο παράδειγμα του `examples.ts`, βλ. `src/lib/voice/guide.test.ts`).

## «Πες το»: φωνή

- Η αναγνώριση ομιλίας γίνεται από τον browser του κινητού (Chrome σε Android, `el-GR`). Όπου δεν υπάρχει, γράφεις στο κουτί ή πατάς το μικρόφωνο του πληκτρολογίου (υπαγόρευση). Θέλει άδεια μικροφώνου και HTTPS.
- Η κατανόηση της φράσης γίνεται τοπικά (`src/lib/voice/interpret.ts`, χωρίς API). Για μοντέλο μέσω API ή δικό σας AI: ένα αντικείμενο που υλοποιεί το `Interpreter` (`src/lib/voice/types.ts`, μπορεί να είναι async) μπαίνει στη σταθερά `interpreter` στην αρχή του `src/pages/Voice.tsx`. Αν αποτύχει, η οθόνη γυρνάει στον τοπικό. Κλειδιά API δεν μπαίνουν στον browser: η κλήση πρέπει να περνάει από δικό σας server (π.χ. Supabase Edge Function).
- Εγκατάσταση στο κινητό: Chrome → μενού → «Προσθήκη στην αρχική οθόνη». Ανοίγει κατευθείαν στο «Πες το» (`public/manifest.webmanifest`).
